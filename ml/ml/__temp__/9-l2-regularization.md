# L2-регуляризация

## 1. Аналитическая ridge-регрессия

Аппроксимировать f(x)=0.1*x+0.1*x**2-0.5*sin(2*x)+cos(4*x)+10 на [-3,4] полиномом с 22 коэффициентами. По X_train,y_train найти w=(X_train^T X_train+lambda*I)^(-1)X_train^T y_train, исключив свободный член из штрафа (I[0,0]=0). Среднюю квадратичную ошибку Q посчитать на всех исходных отсчётах, не только обучающих. Сохранить w и Q, без вывода.

### Решение

```python
import numpy as np


def func(x):
    return 0.1 * x + 0.1 * x ** 2 - 0.5 * np.sin(2 * x) + 1 * np.cos(4 * x) + 10


x = np.arange(-3.0, 4.1, 0.1)  # значения по оси абсцисс (Ox) с шагом 0,1
y = np.array(func(x))  # значения функции по оси ординат

N = 22  # размер признакового пространства (степень полинома N-1)
lm = 20  # параметр лямбда для L2-регуляризатора

X = np.array([[a ** n for n in range(N)] for a in x])  # матрица входных векторов
IL = np.array([[lm if i == j else 0 for j in range(N)] for i in range(N)])  # матрица lambda*I
IL[0][0] = 0  # первый коэффициент не регуляризуем

X_train = X[::2]  # обучающая выборка (входы)
Y_train = y[::2]  # обучающая выборка (целевые значения)

w = np.linalg.inv(X_train.T @ X_train + IL) @ X_train.T @ Y_train

Q = np.mean(np.square(X @ w - y))
```

## 2. SGD с L2-штрафом

Приблизить f(x)=0.5*x+0.2*x**2-0.05*x**3+0.2*sin(4*x)-2.5 на [-4,6] полиномом с пятью коэффициентами. Обучить мини-батчевым SGD с квадратичной потерей и L2-штрафом, не штрафуя w0. Сохранить w, полный MSE в Q и скользящую оценку риска Qe. Параметры — из заготовки. Дополнительно сравнить с обучением без регуляризации и построить графики.

### Исходные данные и заготовка

```python
k = np.random.randint(0, sz-batch_size-1) # sz - размер выборки (массива coord_x)
```

### Решение

```python
import numpy as np

def func(x):
    return 0.5 * x + 0.2 * x ** 2 - 0.05 * x ** 3 + 0.2 * np.sin(4 * x) - 2.5

def model(X, w):
    return X @ w

def loss(y_pred, y_true):
    return np.mean(np.square(y_pred - y_true))

def gradient(X, y, w):
    return (2 / X.shape[0]) * X.T @ (model(X, w) - y)

coord_x = np.arange(-4.0, 6.0, 0.1)                     # значения по оси абсцисс [-4; 6] с шагом 0.1
coord_y = func(coord_x)                                 # значения функции по оси ординат

N = 5                                                   # сложность модели (полином степени N-1)
lm_l2 = 2                                               # коэффициент λ для L2-регуляризатора
sz = len(coord_x)                                       # количество значений функций (точек)
eta = np.array([0.1, 0.01, 0.001, 0.0001, 0.000002])    # шаг обучения для каждого параметра w
w = np.zeros(N)                                         # начальные нулевые значения параметров модели
n_iter = 500                                            # число итераций алгоритма SGD
lm = 0.02                                               # значение λ
batch_size = 20                                         # размер мини-батча (величина K = 20)

X = np.array([coord_x ** n for n in range(N)]).T        # матрица признаков x 
y = coord_y                                             # целевые метки y

np.random.seed(0)  # генерация одинаковых последовательностей псевдослучайных чисел

Qe = loss(model(X, w), y)  # начальное значение среднего эмпирического риска

# Градиентный спуск с регуляризацией
for epoch in range(n_iter):
    # Формирование батча
    k = np.random.randint(0, sz - batch_size - 1)  # случайный выбор начального индекса для батча
    batch = np.arange(k, k + batch_size)  # набор индексов для мини-батча

    Qk = loss(model(X[batch], w), y[batch])  # вычисление ошибки на батче
    Qe = lm * Qk + (1 - lm) * Qe  # обновление скользящего среднего

    weights = np.array([0, *w[1:]])  # регуляризация только для w[1:] (без смещения w0)
    w -= eta * (gradient(X[batch], y[batch], w) + lm_l2 * weights)  # обновление с учётом регуляризации

Q = loss(model(X, w), y)  # итоговое значение среднего эмпирического риска

# Вывод результатов
# print(f'Вектор параметров w = {w.tolist()}')
# print(f'Последнее значение скользящего среднего Qe = {Qe}')
# print(f'Cреднее эмпирического риска (показатель качества) Q = {Q}')
```

## 3. Повторение ridge-регрессии в уроке SVD

**Задача на повторение / аналог предыдущей.**

Повторение ridge-регрессии: приблизить f(x)=0.1*x+0.1*x**2-0.5*sin(2*x)+cos(4*x)+10 на [-3,4] полиномом с 22 коэффициентами. Аналитически найти w по X_train,y_train с L2-штрафом и I[0,0]=0. MSE Q считать по всей сетке x, не только обучающей. Сохранить w,Q; не печатать.

### Решение

```python
import numpy as np


def func(x):
    return 0.1 * x + 0.1 * x ** 2 - 0.5 * np.sin(2*x) + 1 * np.cos(4*x) + 10


x = np.arange(-3.0, 4.1, 0.1) # значения по оси абсцисс (Ox) с шагом 0,1
y = np.array(func(x)) # значения функции по оси ординат

N = 22  # размер признакового пространства (степень полинома N-1)
lm = 20  # параметр лямбда для L2-регуляризатора
X_func = lambda x : np.array([x**n for n in range(N)])
X = np.array([[a ** n for n in range(N)] for a in x])  # матрица входных векторов
IL = np.array([[lm if i == j else 0 for j in range(N)] for i in range(N)])  # матрица lambda*I
IL[0][0] = 0  # первый коэффициент не регуляризуем

X_train = X[::2]  # обучающая выборка (входы)
Y_train = y[::2]  # обучающая выборка (целевые значения)

w = np.linalg.inv(X_train.T @ X_train + IL) @ X_train.T @ Y_train
model = lambda x,w : np.dot(x,w)
Q = 0 
for i in range(len(y)):
    xi = X_func(x[i])
    Q += (y[i] - model(xi,w))**2
Q = Q / len(y)
```
