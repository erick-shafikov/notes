## 1. Информационный выигрыш по Джини

Для сгенерированного булева массива X длины 200 вычислить информационный выигрыш разбиения при t=150. Impurity оценивать по Джини: G=1-sum(p_k**2); IG равен impurity всей выборки минус взвешенные impurity частей. Сохранить IG; без вывода.

### Исходные данные и заготовка

```python
import numpy as np

np.random.seed(0)
X = np.random.randint(0, 2, size=200)
```

### Решение

```python
import numpy as np

np.random.seed(0)
X = np.random.randint(0, 2, size=200)
S = lambda x: 1 - np.sum((np.bincount(x) / len(x)) ** 2)
t = 150

# Вычисление IG
S0, S_left, S_right = S(X), S(X[:t]), S(X[t:])
IG = S0 - (len(X[:t]) / len(X) * S_left + len(X[t:]) / len(X) * S_right)
```
