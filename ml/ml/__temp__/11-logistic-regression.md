## 2. Признаки для вероятности 0.5

```python
# Условие:
# При w=[20,-1,3,5,-0.15] подобрать любой вектор x, для которого логистическая модель выдаёт
# вероятность класса +1, равную 0.5. Сохранить x как список или кортеж, без вывода.

import numpy as np
w = np.array([20, -1, 3, 5, -0.15])
y = 1
p = 0.5

M = -np.log(1/p - 1)

x = 1/w

x *= M / (w * y)
```
