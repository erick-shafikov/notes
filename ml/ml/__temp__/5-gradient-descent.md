# Градиентный спуск

## 1. Минимизация функции одной переменной

Найти локальный минимум f(x)=0.5*x+0.2*x**2-0.1*x**3 обычным градиентным спуском. Начало x=-4, шаг 0.01, ровно 200 итераций. Итог сохранить в x, без вывода.

### Решение

```python
import numpy as np


def func(x):
    return 0.5 * x + 0.2 * x ** 2 - 0.1 * x ** 3


def df(x):
    return 0.5 + 0.4*x - 0.3 * x ** 2


coord_x = np.arange(-5.0, 5.0, 0.1) # значения по оси абсцисс
coord_y = func(coord_x) # значения по оси ординат (значения функции)

N = 200
x = -4
lmd = 0.01

for i in range(N + 1):
    x = x - lmd * df(x)
```

## 2. Обучение полинома полным градиентом

Аппроксимировать f(x)=0.1*x**2-sin(x)+5 на [-5,5] полиномом третьей степени. Применить полный градиентный спуск для средней квадратичной ошибки; начальные веса, скорости и число итераций заданы в заготовке. Сохранить w и итоговый MSE в Q; не печатать.

### Решение

```python
import numpy as np

# исходная функция, которую нужно аппроксимировать моделью a(x)
def func(x):
    return 0.1 * x**2 - np.sin(x) + 5.

coord_x = np.arange(-5.0, 5.0, 0.1) # значения по оси абсцисс [-5; 5] с шагом 0.1
coord_y = func(coord_x) # значения функции по оси ординат

eta = np.array([0.1, 0.01, 0.001, 0.0001]) # шаг обучения для каждого параметра w0, w1, w2, w3
w = np.array([0., 0., 0., 0.]) # начальные значения параметров модели
N = 200 # число итераций градиентного алгоритма

X = np.power(coord_x.reshape(-1, 1), range(4))
for _ in range(N):
    y_pred = X @ w
    w -= eta * 2 * ((y_pred - coord_y) * X.T).mean(1)

Q = np.square(y_pred - coord_y).mean()
```

## 3. Повторение градиентного спуска в уроке кластеризации

**Задача на повторение / аналог предыдущей.**

Повторение обычного градиентного спуска: минимизировать f(x)=0.5*x+0.2*x**2-0.1*x**3, начиная с x=-4. Использовать eta=0.01 и ровно 200 шагов x-=eta*f′(x). Итог записать в x, без вывода.

### Решение

```python
import numpy as np

def func(x):
    return 0.5 * x + 0.2 * x ** 2 - 0.1 * x ** 3

def df(x):
    return 0.5 + 0.4 * x - 0.3 * x ** 2

eta = 0.01
x_current = -4.0
N = 200

for i in range(N):
    x_current = x_current - eta * df(x_current)

x = x_current
```
