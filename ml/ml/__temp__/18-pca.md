## 1. Матрица Грама и её спектр

Для матрицы X из заготовки (5 признаков, 1000 объектов) вычислить матрицу Грама признаков F размера 5×5. Через np.linalg.eig получить собственные числа L и собственные векторы W. Сохранить F,L,W, без вывода. Учитывать, что признаки расположены по строкам X.

### Исходные данные и заготовка

```python
import numpy as np

np.random.seed(0)

# исходные параметры для формирования образов обучающей выборки
r = 0.7
D = 3.0
mean = [3, 7, -2, 4, 6]
n_feature = 5
V = [[D * r ** abs(i-j) for j in range(n_feature)] for i in range(n_feature)]

# моделирование обучающей выборки
N = 1000
X = np.random.multivariate_normal(mean, V, N).T
```

### Решение

```python

# моделирование обучающей выборки
N = 1000
X = np.random.multivariate_normal(mean, V, N).T

# вычисление матрицы Грама
F = (1 / N) * X @ X.T

# вычисление собственных чисел и собственных векторов
L, W = np.linalg.eig(F)
```

## 4. Снижение размерности перед регрессией

Для функции f(x)=0.5*x+0.2*x**2-0.05*x**3+0.2*sin(4*x)-3 построить главные компоненты по матрице Грама X_train. Собственные векторы упорядочить по убыванию собственных чисел. Спроецировать полную X, оставив 7 признаков (G размера l×7). По исходному правилу отбора сформировать XX_train и обучить МНК на XX_train,Y_train. Восстановление по полной G сохранить в predict; самостоятельно сравнить другое число компонент. Без вывода.

### Исходные данные и заготовка

```python
sort_ind = np.argsort(L)[::-1]
WW = W[:,sort_ind]
```

### Решение

```python
import numpy as np


def func(x):
    return 0.5 * x + 0.2 * x ** 2 - 0.05 * x ** 3 + 0.2 * np.sin(4 * x) - 3


coord_x = np.arange(-4.0, 6.0, 0.1)
coord_y = func(coord_x)
coord_y = coord_y - np.mean(coord_y)  # центрирование функции

K = 10
X = np.array([[xx**i for i in range(K)] for xx in coord_x]) # обучающая выборка для поиска коэффициентов модели
Y = coord_y

X_train = X[::2]  # обучающая выборка (входы)
Y_train = Y[::2]  # обучающая выборка (целевые значения)

# здесь продолжайте программу
N = len(X_train)
F = 1/N * X_train.T @ X_train
L, W = np.linalg.eig(F)

sort_ind = np.argsort(L)[::-1]
WW = W[:,sort_ind]

L = np.flip(np.sort(L))
G = X @ WW

G = G[:, :7]
XX_train = G[::2]

A = np.matmul(XX_train.T, XX_train)
w = np.linalg.inv(A) @ XX_train.T @ Y_train

predict = G @ w
```
