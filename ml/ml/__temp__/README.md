Собрано из [курса Stepik 209247](https://stepik.org/course/209247/syllabus) 29.10.2026. Условия пересказаны своими словами. Каждая задача оформлена одним самостоятельным Python-блоком: условие находится в комментариях, затем идут входные данные, необходимые определения и решение. Блок можно целиком скопировать в отдельный файл и запустить; код других задач не требуется. Рисунки сохранены рядом с соответствующими задачами.

Для всех примеров нужны Python 3 и библиотеки `numpy`, `scipy`, `matplotlib`, `scikit-learn`, `sympy`. Их можно установить командой `python -m pip install numpy scipy matplotlib scikit-learn sympy`. Примеры с графиками открывают окно Matplotlib; остальные сохраняют результаты в переменных, указанных в условии, и выводят их только там, где это требуется.

Исходные 109 блоков проверены отдельным запуском в Python 3.11. После сопоставления с основными конспектами из этой папки удалена 51 повторная задача. Здесь оставлены 58 задач, для которых отдельного соответствующего примера в конспектах нет. Совпадение алгоритма при других данных или другой цели само по себе не считалось дублем.

Для совпавших задач выбраны или объединены реализации в 25 основных конспектах `ml/ml`. Все 49 соответствующих блоков проверены отдельным запуском; примеры, у которых не было пары в этой подборке, сохранены без изменений.
