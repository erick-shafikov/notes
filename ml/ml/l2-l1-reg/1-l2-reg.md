# l2 регуляризатор

При обучении модели возникает проблема — переобученность модели. Такое может происходить из-за высокой сложности модели, большого числа признаков или шума в данных.

**Почему большие веса ведут к переобучению.** Вес $\omega_j$ показывает, насколько сильно признак $x_j$ влияет на предсказание: $a(x) = \sum_j \omega_j x_j$. Если веса большие по модулю, модель резко реагирует на малейшие изменения признаков — небольшой шум во входных данных вызывает большое отклонение предсказания. В результате модель «запоминает» шум обучающей выборки и выдаёт вычурные изогнутые поверхности там, где реальная зависимость гладкая. Хочется ограничить размер весов, чтобы модель оставалась плавной и не подстраивалась под случайные выбросы.

Как решение — добавить регуляризацию в функцию потерь: $L_i^{reg}(ω) = L_i(ω) + λ / 2 ||ω|| ^ 2$, при минимизации $L_i(ω) + λ / 2 ||ω|| ^ 2 → min$. Тогда градиент регуляризованной функции: $∇L_i^{reg}(ω) = ∇L_i(ω) + λ * ω$. Пересчет весов: $ω_{t + 1} = ω_t - η * ∇L_i^{reg}(ω_t) = ω_t - η * ( ∇L_i(ω_t) + λ * ω_t)$, откуда $ω_{t + 1} = (1 - η * λ) * ω_t - η * ∇L_i(ω_t)$. Такая функция потерь — MSE с L2-регуляризатором — называется Ridge (гребенчатая регрессия).

## Числовой пример

Рассмотрим элементарную модель: $a(x) = w_1 x_1 + w_2 x_2$. Дан один обучающий объект с **зашумлённой** меткой: $x = [1,\, 1]$, $y = 8$ (истинное значение ≈ 2, шум +6). Стартуем с нулей: $w_1 = w_2 = 0$, шаг $\eta = 0.1$.

Градиент MSE по весу $w_j$: $\nabla_{w_j} L = 2(a - y)\,x_j = 2(w_1 + w_2 - 8)$.

**Без регуляризации:** $w_j \leftarrow w_j - \eta \cdot \nabla_{w_j} L$

**С L2 ($\lambda = 2$):** $w_j \leftarrow (1 - \eta\lambda)\,w_j - \eta \cdot \nabla_{w_j} L = 0.8\,w_j - \eta \cdot \nabla_{w_j} L$

| Шаг | $a$ (без L2) | $w_1 = w_2$ (без L2) | $a$ (L2) | $w_1 = w_2$ (L2) |
| --- | ------------ | -------------------- | -------- | ---------------- |
| 0   | 0.00         | 0.00                 | 0.00     | 0.00             |
| 1   | 3.20         | 1.60                 | 3.20     | 1.60             |
| 2   | 5.12         | 2.56                 | 4.48     | 2.24             |
| 3   | 6.27         | 3.14                 | 4.99     | 2.50             |
| 4   | 6.97         | 3.48                 | 5.20     | 2.60             |
| ∞   | 8.00         | **4.00**             | 5.33     | **2.67**         |

Без регуляризации веса уходят к 4 — модель запоминает шум, предсказывая ровно $a = 8$. С L2 веса стабилизируются у 2.67: на каждом шаге множитель $0.8$ подтягивает их к нулю, не давая подстроиться под зашумлённую метку.

Если рассматривать Ridge как линейную регрессию с L2-регуляризацией (название «гребенчатая» происходит от формы гребня на поверхности функции потерь при изменении $\lambda$). Рассмотрим функцию потерь $L_i(ω) = (a(x_i, ω) - y_i) ^ 2$, где $a(x_i, ω) = <w, x> = w ^ T * x$, если применить L2: $L_i(ω) = (ω ^ T x_i - y_i) ^ 2 + λ / 2 * ω ^ T * ω$. Если расписать в матричном виде: $Q(ω, X) = (1 / 2) * (X * ω - Y) ^ T * (X * ω - Y) + (λ / 2) * ω ^ T * ω$, где X — матрица объектов выборки. При $Q'(ω) = 0$ получается $ω = (X ^ T * X + λ * I) ^ {-1} * X ^ T * Y$.

Роль L2 видна и через обусловленность. При зависимых столбцах $X$ или числе объектов меньше числа признаков матрица $X^T X$ вырождена; при почти зависимых — чувствительна к малым изменениям данных. Если штрафуются все коэффициенты, добавление $\lambda I$, $\lambda>0$, заменяет собственные числа $s_j$ на $s_j+\lambda$ и делает матрицу обратимой. При исключённом bias вместо $I$ используется $D=\operatorname{diag}(0,1,\ldots,1)$: свободный член остаётся без штрафа. Так регуляризация ограничивает неустойчивые направления, сохраняя само число признаков.

## вычисление с помощью l2 регуляризатора

```python

import numpy as np

x = np.arange(0, 10.1, 0.1)
y = np.array([a ** 3 - 10 * a ** 2 + 3 * a + 500 for a in x])  # функция в виде полинома x^3 - 10x^2 + 3x + 500
x_train, y_train = x[::2], y[::2]
N = 13  # размер признакового пространства (степень полинома N-1)
L = 20  # при увеличении N увеличивается L (кратно): 12; 0.2   13; 20    15; 5000

X = np.array([[a ** n for n in range(N)] for a in x])  # матрица входных векторов
IL = np.array([[L if i == j else 0 for j in range(N)] for i in range(N)])  # матрица lambda*I
IL[0][0] = 0  # первый коэффициент не регуляризуем
X_train = X[::2]  # обучающая выборка
Y = y_train  # обучающая выборка

# вычисление коэффициентов по формуле w = (XT*X + lambda*I)^-1 * XT * Y
A = np.linalg.inv(X_train.T @ X_train + IL)
w = A @ X_train.T @ Y

Q = np.mean(np.square(X @ w - y))
```

> **Почему `IL[0][0] = 0`:** свободный член $\omega_0$ (bias) сдвигает предсказание модели вверх или вниз целиком — он не влияет на форму поверхности и расположение экстремумов. Регуляризация нужна чтобы ограничить изгибы модели, bias на форму не влияет, поэтому его не штрафуют.

## Weight decay vs L2

Раскрыв шаг обновления весов при L2-регуляризации в SGD, получаем:

$$\omega_{t+1} = \omega_t - \eta\,\nabla L_i(\omega_t) - \eta\lambda\,\omega_t = (1 - \eta\lambda)\,\omega_t - \eta\,\nabla L_i(\omega_t)$$

Множитель $(1 - \eta\lambda)$ перед $\omega_t$ называется **weight decay** — на каждом шаге веса немного «затухают», уменьшаясь в $(1 - \eta\lambda)$ раз независимо от градиента. В SGD L2-регуляризация и weight decay — это одно и то же, просто разные способы записи одной операции.

Различие появляется в **адаптивных методах** (Adam, RMSProp). В Adam градиент сначала накапливается в моменты $V$ и $g$, и только потом масштабируется:

$$V_{t+1} = \gamma V_t + (1-\gamma)\,\nabla L_i(\omega_t), \qquad g_{t+1} = \alpha g_t + (1-\alpha)\,(\nabla L_i(\omega_t))^2$$

$$\omega_{t+1} = \omega_t - \eta\,\frac{\hat{V}_{t+1}}{\sqrt{\hat{g}_{t+1}} + \varepsilon}$$

При наивном добавлении L2 штраф $\lambda\omega$ прибавляется к градиенту **до** вычисления моментов — то есть вместо $\nabla L_i(\omega_t)$ везде подставляется $\nabla L_i(\omega_t) + \lambda\omega_t$. Этот суммарный градиент попадает внутрь $V$ и $g$, а значит $\lambda\omega$ тоже проходит через адаптивное масштабирование $1/(\sqrt{\hat{g}_{t+1}} + \varepsilon)$. Признаки с редкими обновлениями имеют маленький $\hat{g}$ и большой эффективный шаг — штраф для них усиливается, для частых — ослабляется. Регуляризация теряет равномерность.

**AdamW** решает это, отделяя weight decay от градиента — штраф применяется напрямую к весам уже после адаптивного шага:

$$\omega_{t+1} = \omega_t - \eta\,\frac{\hat{V}_{t+1}}{\sqrt{\hat{g}_{t+1}} + \varepsilon} - \eta\lambda\,\omega_t$$

Так все веса затухают одинаково, независимо от истории их градиентов. Поэтому для Adam правильная регуляризация — это AdamW с явным weight decay, а не L2 через функцию потерь.

|                                | SGD          | Adam (L2)           | AdamW                |
| ------------------------------ | ------------ | ------------------- | -------------------- |
| L2 и weight decay              | эквивалентны | **не эквивалентны** | weight decay отделён |
| Штраф масштабируется адаптивно | —            | да (нежелательно)   | нет                  |

L2 регуляризация уменьшает значения весов (делает их более гладкими), но не зануляет их.

## l2 + sgd

```python
import numpy as np


# исходная функция, которую нужно аппроксимировать моделью a(x)
def func(x):
    return 0.5 * x + 0.2 * x ** 2 - 0.05 * x ** 3 + 0.2 * np.sin(4 * x) - 2.5


# модель
def model(w, x):
    xv = np.array([x ** n for n in range(len(w))])
    return w.T @ xv


# функция потерь
def loss(w, x, y):
    return (model(w, x) - y) ** 2


# производная функции потерь
def dL(w, x, y):
    xv = np.array([x ** n for n in range(len(w))])
    return 2 * (model(w, x) - y) * xv


coord_x = np.arange(-4.0, 6.0, 0.1)  # значения по оси абсцисс [-4; 6] с шагом 0.1
coord_y = func(coord_x)  # значения функции по оси ординат

N = 5  # сложность модели (полином степени N-1)
lm_l2 = 2  # коэффициент лямбда для L2-регуляризатора
sz = len(coord_x)  # количество значений функций (точек)
eta = np.array([0.1, 0.01, 0.001, 0.0001, 0.000002])  # шаг обучения для каждого параметра w0, w1, w2, w3, w4
w = np.zeros(N)  # начальные нулевые значения параметров модели
n_iter = 500  # число итераций алгоритма SGD
lm = 0.02  # значение параметра лямбда для вычисления скользящего экспоненциального среднего
batch_size = 20  # размер мини-батча (величина K = 20)

Qe = loss(w, coord_x, coord_y).mean()  # начальное значение среднего эмпирического риска
np.random.seed(0)  # генерация одинаковых последовательностей псевдослучайных чисел

for _ in range(n_iter):
    k = np.random.randint(0, sz - batch_size - 1)
    batch = np.arange(k, k + batch_size)
    batch_x = coord_x[batch]
    batch_y = coord_y[batch]

    Qe = lm * loss(w, batch_x, batch_y).mean() + (1 - lm) * Qe

    w1 = np.array(w)
    w1[0] = 0

    w -= eta * (dL(w, batch_x, batch_y).mean(axis=1) + lm_l2 * w1)

Q = loss(w, coord_x, coord_y).mean()

```

> **`w1[0] = 0`** — свободный член не регуляризуется, см. выше.
