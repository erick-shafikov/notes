**DBSCAN** (Density-Based Spatial Clustering of Applications with Noise) — алгоритм кластеризации, основанный на плотности точек в окрестности, а не на расстоянии до центроида. В отличие от k-means, он не требует заранее задавать число кластеров и находит группы произвольной формы.

**Ключевые понятия.** Задаются два параметра: $\varepsilon > 0$ — радиус окрестности и $m \in \mathbb{N}$ — минимальное число точек. $\varepsilon$-окрестность объекта $x$:

$$U_\varepsilon(x) = \{u \in X^l : \rho(x, u) \leq \varepsilon\}$$

где $\rho$ — метрика в признаковом пространстве, $X^l$ — вся обучающая выборка.

**Три типа объектов:**

- **Корневой** — $|U_\varepsilon(x)| \geq m$: окрестность содержит не менее $m$ объектов; такие точки образуют «ядро» кластера
- **Граничный** — не корневой, но попадает в $\varepsilon$-окрестность хотя бы одного корневого объекта
- **Шумовой** — не корневой и не граничный; не принадлежит ни одному кластеру

![Типы объектов DBSCAN и пример кластеризации](images/dbscan-concept.png)

**Алгоритм DBSCAN.**

Вход: выборка $X^l = \{x_1, \ldots, x_l\}$, параметры $\varepsilon$ и $m$.
Выход: разбиение на кластеры $K_1, K_2, \ldots$ и множество шумовых выбросов $N$.

**Идея простыми словами.** Кластер растёт как «пожар»: загорается от одной плотной (корневой) точки и перекидывается на всех её соседей. Если сосед тоже плотный — огонь идёт дальше от него. Если сосед неплотный (граничный) — он сгорает, но дальше огонь от него не идёт. Когда распространяться больше некуда, кластер готов — берём следующую ещё не тронутую точку и повторяем.

Обозначения: $U$ — объекты, которые ещё ни разу не рассматривались; $N$ — кандидаты в шум; $a$ — номер текущего кластера.

**Шаг 1. Подготовка.** Все точки считаем непросмотренными: $U \leftarrow X^l$. Шума пока нет: $N \leftarrow \emptyset$. Кластеров пока нет: $a \leftarrow 0$.

**Шаг 2. Берём любую непросмотренную точку $x \in U$ и считаем её соседей** — сколько точек лежит в круге радиуса $\varepsilon$ вокруг неё, то есть $|U_\varepsilon(x)|$ (сама $x$ тоже считается).

**Шаг 3. Соседей мало ($|U_\varepsilon(x)| < m$) — откладываем точку в шум.**

- $N \leftarrow N \cup \{x\}$, $U \leftarrow U \setminus \{x\}$ — точка просмотрена и помечена как _возможно_ шумовая
- Почему «возможно»: сама по себе точка неплотная, но позже может выясниться, что она лежит рядом с корневой точкой какого-то кластера. Тогда она окажется граничной и будет из шума «спасена» (см. шаг 4)
- Возвращаемся к шагу 2

**Шаг 4. Соседей достаточно ($|U_\varepsilon(x)| \geq m$) — $x$ корневая, запускаем новый кластер.**

- Заводим номер кластера: $a \leftarrow a + 1$
- Кладём в кластер всю окрестность: $K \leftarrow U_\varepsilon(x)$. Все соседи корневой точки точно принадлежат её кластеру — по определению они либо корневые, либо граничные
- **Расширяем кластер.** По очереди проходим точки $x' \in K$, которые ещё не просмотрены или лежат в шуме $N$, и для каждой считаем её соседей:
  - $|U_\varepsilon(x')| \geq m$ — $x'$ тоже корневая, значит её соседи тоже наши: $K \leftarrow K \cup U_\varepsilon(x')$. Новые точки встают в ту же очередь на проверку — так кластер «ползёт» по плотной области
  - $|U_\varepsilon(x')| < m$ — $x'$ граничная: она остаётся в кластере, но её соседей не добавляем. Именно поэтому кластер не «перетекает» через редкие точки в соседний кластер. Если $x'$ раньше попала в $N$, она оттуда уходит — её спасли
- Расширение заканчивается, когда в $K$ не осталось непроверенных точек: все корневые точки кластера уже раскрыты
- Всем точкам кластера ставим метку $a$ и убираем их из непросмотренных: $U \leftarrow U \setminus K$

**Шаг 5. Повторяем шаги 2–4, пока есть непросмотренные точки** ($U \neq \emptyset$). Каждая новая корневая точка, не попавшая ни в один из прошлых кластеров, открывает следующий кластер.

**Шаг 6. Итог.** Точки, оставшиеся в $N$ (их так и не «подобрал» ни один кластер), — шумовые выбросы. Остальные разбиты на кластеры $K_1, K_2, \ldots$

**Что важно запомнить:**

- Новый кластер может начать только корневая точка
- Расширяют кластер только корневые точки; граничные лишь присоединяются к нему
- Пометка «шум» не окончательная до конца алгоритма — граничную точку можно встретить раньше её кластера
- Граничная точка, лежащая рядом с корневыми точками двух разных кластеров, достаётся тому кластеру, который дошёл до неё первым (результат для таких точек зависит от порядка обхода)

Преимущества:

- Находит кластеры произвольной формы (полумесяц, спираль и т.д.) — недостижимо для k-means
- Не требует задавать число кластеров заранее
- Автоматически выделяет шумовые выбросы как отдельный «класс»
- Сложность $O(l \cdot \overline{|U_\varepsilon|})$ — при использовании пространственного индекса близко к $O(l \log l)$

Недостатки:

- При разной плотности кластеров единый $\varepsilon$ работает плохо
- Чувствителен к выбору $\varepsilon$ и $m$: их нужно подбирать под данные
- Плохо масштабируется на высокую размерность (проклятие размерности делает все точки «далёкими»)

**Числовой пример.** Восемь точек на плоскости, $\varepsilon = 1.5$, $m = 3$:

| Точка | Координаты |
| ----- | ---------- |
| A     | $(0, 0)$   |
| B     | $(1, 0)$   |
| C     | $(0, 1)$   |
| G     | $(2, 0)$   |
| D     | $(4, 4)$   |
| E     | $(5, 4)$   |
| F     | $(4, 5)$   |
| H     | $(8, 0)$   |

Для каждой точки вычислим $|U_\varepsilon(x)|$ — количество точек в $\varepsilon$-окрестности (включая саму точку):

| Точка | Соседи в $U_{1.5}$                                   | $\|U_\varepsilon\|$ | Тип                                      |
| ----- | ---------------------------------------------------- | ------------------- | ---------------------------------------- |
| A     | A, B $(\rho=1)$, C $(\rho=1)$                        | 3                   | **корневой**                             |
| B     | B, A $(\rho=1)$, C $(\rho\approx1.41)$, G $(\rho=1)$ | 4                   | **корневой**                             |
| C     | C, A $(\rho=1)$, B $(\rho\approx1.41)$               | 3                   | **корневой**                             |
| G     | G, B $(\rho=1)$                                      | 2                   | **граничный** ($G \in U_\varepsilon(B)$) |
| D     | D, E $(\rho=1)$, F $(\rho=1)$                        | 3                   | **корневой**                             |
| E     | E, D $(\rho=1)$, F $(\rho\approx1.41)$               | 3                   | **корневой**                             |
| F     | F, D $(\rho=1)$, E $(\rho\approx1.41)$               | 3                   | **корневой**                             |
| H     | H                                                    | 1                   | **шумовой**                              |

Алгоритм обрабатывает точки последовательно. Пусть первой взята A — корневая, создаём **кластер 1**: добавляем $U_\varepsilon(A) = \{A, B, C\}$. B тоже корневая → расширяем: $U_\varepsilon(B)$ добавляет G. G не корневая → присоединяется как граничная, не расширяет кластер. C корневая → $U_\varepsilon(C)$ не даёт новых точек. Кластер 1 = $\{A, B, C, G\}$.

Далее первой непомеченной окажется D — создаём **кластер 2** аналогично: D, E, F — все корневые, расширение не добавляет новых. Кластер 2 = $\{D, E, F\}$.

H не попала ни в один кластер — **шумовой выброс**.

Итог: два кластера $\{A, B, C, G\}$ и $\{D, E, F\}$, шум $\{H\}$.

# Алгоритм DBSCAN, взято с сайта: https://habr.com/ru/post/322034/

from itertools import cycle
from math import hypot
from numpy import random
import matplotlib.pyplot as plt


# идем по всем точкам внешним циклом, каждая точка посещается один раз
# (квадратичная сложность из-за region_query, который каждый раз перебирает все точки P)
# смотрим на точку:
# - если достаточное количество соседей,то
# - - то образуем из нее кластер, далее анализируем ее и всех ее подходящих соседей
# - если нет
# - - потенциально шумовая
def dbscan_naive(P, eps, m, distance):
    NOISE = 0 # ключ для шумовых элементов, то есть в clusters по ключу 0 будет лежать весь шум
    C = 0 # номер текущего кластера (счетчик)

    visited_points = set() # точка может быть посещенная, но не принадлежавшая какому-то кластеру
    clustered_points = set() # точки принадлежащие какому-либо кластеру
    clusters = {NOISE: []} # набор кластеров

    def region_query(p):
        return [q for q in P if distance(p, q) <= eps] # фильтр по расстоянию, сама p тоже попадает в список (distance(p, p) = 0)

    def expand_cluster(p, neighbours): # функция для создания нового кластера. Вход - корневая точка p и все ее соседи в eps-окрестности. p начинает новый кластер C: до вызова она не была ни в каком кластере (все точки кластеров уже посещены, а сюда приходят только непосещенные)
        if C not in clusters: # кластер C всегда новый, так как C только что увеличили, условие всегда выполняется
            clusters[C] = [] # то создать по индексу
        clusters[C].append(p) # точку в кластер
        clustered_points.add(p) # добавить точку как образующую кластер - С
        # цикл проверяет посещенная ли точка и есть ли она в кластере или в просмотренных
        # дополняя изначальных соседей которые были на вход функции
        while neighbours: # посмотрим на всех кто подходит по предварительному расстоянию
            q = neighbours.pop() # проверим каждого
            if q not in visited_points: # если точку еще не посещали - ветка расширения кластера: считаем соседей q и, если q корневая, добавляем их в очередь. Шумовые точки уже посещены во внешнем цикле, поэтому сюда не попадают и кластер не расширяют
                visited_points.add(q) # пометить как посещенную
                neighbourz = region_query(q) # найти всех соседей среди ВСЕХ точек у этой рассматриваемой точки
                if len(neighbourz) >= m: # q корневая
                    neighbours.extend(neighbourz) # то дополнить очередь всеми соседями q, дубликаты возможны, но повторно их отсекут проверки visited_points и clustered_points
            if q not in clustered_points: # если точка не принадлежит ни одному кластеру (граничная точка, уже забранная другим кластером, остается в нем - отсюда зависимость от порядка обхода)
                clustered_points.add(q) # добавить ее в точки, которые принадлежат кластеру
                clusters[C].append(q) # добавить ее в кластер С
                if q in clusters[NOISE]: # если была в шумовых - это граничная точка: неплотная, но рядом с корневой (ветка для удаления из шумовых)
                    clusters[NOISE].remove(q) # то удалить

    for p in P: # по всем точкам
        if p in visited_points: # мы ее посещали - пропускаем
            continue
        visited_points.add(p) # если не посещали, то помечаем как посещенную
        neighbours = region_query(p) # находим все кто подходит по расстоянию из ВСЕХ точек
        if len(neighbours) < m: # если их меньше заданного количества
            clusters[NOISE].append(p) # помечаем как потенциально шумовая
        else: # если их больше или равно m - точка корневая
            C += 1 # заводим номер нового кластера
            expand_cluster(p, neighbours) # разбираемся с соседями, которые близки по кластеру

    return clusters
