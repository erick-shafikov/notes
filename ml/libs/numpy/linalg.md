# np.linalg.det

Вычисляет **определитель** квадратной матрицы.

```python
np.linalg.det(A)
```

Свойства:

- матрица должна быть квадратной, иначе `LinAlgError`
- если $\det A = 0$ — матрица вырождена, обратной не существует
- результат `float64` (даже для целочисленного входа)
- поддерживает батч: вход `(batch, n, n)` → выход `(batch,)`

```python
A = np.array([[1, 2],
              [3, 4]])

np.linalg.det(A)  # -2.0  (= 1*4 - 2*3)

# вырожденная матрица
B = np.array([[1, 2],
              [2, 4]])
np.linalg.det(B)  # 0.0
np.linalg.inv(B)  # LinAlgError: Singular matrix
```

Геометрический смысл: $|\det A|$ — коэффициент масштабирования объёма при линейном преобразовании $A$. Для ковариационной матрицы $\Sigma$ определитель отвечает за нормировку многомерного гауссиана: чем шире распределение, тем больше $\det\Sigma$ и тем меньше пик плотности.

# np.linalg.eig

Вычисляет собственные значения и правые собственные векторы квадратной матрицы.

```python
eigenvalues, eigenvectors = np.linalg.eig(A)
```

- `eigenvalues` — массив `(n,)` собственных значений (могут быть комплексными даже для вещественной `A`)
- `eigenvectors` — матрица `(n, n)`, где **столбец** `eigenvectors[:, i]` — собственный вектор для `eigenvalues[i]`
- порядок собственных значений не гарантирован; для симметричных матриц лучше `np.linalg.eigh` — возвращает вещественные значения, отсортированные по возрастанию

```python
import numpy as np

A = np.array([[3, 1],
              [1, 3]])

vals, vecs = np.linalg.eig(A)

print(vals)       # [4. 2.]
print(vecs)       # столбцы — собственные векторы
# [[ 0.707  -0.707]
#  [ 0.707   0.707]]

# проверка: A @ v == λ * v
i = 0
np.allclose(A @ vecs[:, i], vals[i] * vecs[:, i])  # True
```

Для симметричной/эрмитовой матрицы — `eigh` (быстрее, всегда вещественный результат, отсортирован):

```python
vals, vecs = np.linalg.eigh(A)  # vals по возрастанию
```

Связь с SVD: собственные векторы $A^T A$ — это правые сингулярные векторы (`np.linalg.svd`), собственные значения равны $\sigma_j^2$. Для PCA удобнее сразу `svd`, а не явное вычисление `eig(A.T @ A)` — численно устойчивее.

# np.linalg.inv

свойства:

- матрица должна быть квадратной и невырожденной (`det(A) != 0`), иначе `LinAlgError: Singular matrix`
- результат всегда `float64`, проверять через `np.allclose`, не через `==`
- для решения системы `Ax = b` лучше `np.linalg.solve(A, b)` — быстрее и численно стабильнее
- плохо обусловленные матрицы дают неточный результат без ошибки, проверить: `np.linalg.cond(A)` >> 1e10 — опасно
- поддерживает батч: вход `(batch, n, n)` → выход `(batch, n, n)`

```python
import numpy as np

A = np.array([[1, 2],
              [3, 4]])

A_inv = np.linalg.inv(A)
# array([[-2. ,  1. ],
#        [ 1.5, -0.5]])

# проверка: A @ A_inv == I
np.allclose(A @ A_inv, np.eye(2))  # True
```

# np.linalg.slogdet

Вычисляет знак определителя и логарифм его абсолютного значения:

```python
sign, logabsdet = np.linalg.slogdet(A)
```

Результат связан с обычным определителем формулой:

```python
det_A = sign * np.exp(logabsdet)
```

`slogdet` устойчивее выражения `np.log(np.linalg.det(A))`: определитель очень
большой матрицы может переполниться, а очень маленький — округлиться до нуля.

```python
import numpy as np

A = np.array([
    [2.0, 0.0],
    [0.0, 3.0],
])

sign, logabsdet = np.linalg.slogdet(A)

print(sign)       # 1.0
print(logabsdet)  # log(6) = 1.791759...
```

Для положительно определённой ковариационной матрицы `sign` должен быть равен
`1`. Для вырожденной матрицы возвращаются `sign == 0` и `logabsdet == -inf`.

# np.linalg.solve

Решает систему линейных уравнений `A @ x = b` без явного вычисления обратной
матрицы:

```python
x = np.linalg.solve(A, b)
```

- `A` — квадратная матрица коэффициентов формы `(n, n)`;
- `b` — вектор `(n,)` или несколько правых частей формы `(n, k)`;
- если `A` вырождена, возникает `LinAlgError`.

```python
import numpy as np

A = np.array([
    [3.0, 1.0],
    [1.0, 2.0],
])
b = np.array([9.0, 8.0])

x = np.linalg.solve(A, b)

print(x)                    # [2. 3.]
print(np.allclose(A @ x, b))  # True
```

Для решения системы предпочтительнее `solve`, а не `inv`:

```python
x = np.linalg.solve(A, b)   # предпочтительно
x = np.linalg.inv(A) @ b    # лишнее вычисление обратной матрицы
```

# np.linalg.svd

Вычисляет сингулярное разложение матрицы $X = U \Sigma V^T$.

```python
U, s, Vt = np.linalg.svd(X, full_matrices=True)
```

- `U` — левые сингулярные векторы, столбцы ортонормированы; форма `(m, m)` при `full_matrices=True`, `(m, r)` при `False`
- `s` — сингулярные значения `(r,)`, отсортированы по убыванию, $r = \min(m, n)$
- `Vt` — правые сингулярные векторы (уже транспонированные!), форма `(n, n)` или `(r, n)`; строка `Vt[i]` — i-й правый вектор

`full_matrices=False` («тонкий SVD») экономит память: не вычисляет лишние столбцы `U` и строки `Vt`, которые всё равно обнуляются через $\Sigma$.

```python
import numpy as np

X = np.array([
    [3, 2, 2],
    [2, 3, -2],
], dtype=float)

# полный SVD: U (2×2), s (2,), Vt (3×3)
U, s, Vt = np.linalg.svd(X, full_matrices=True)

# тонкий SVD: U (2×2), s (2,), Vt (2×3) — для прямоугольных матриц компактнее
U, s, Vt = np.linalg.svd(X, full_matrices=False)

# восстановление исходной матрицы
X_rec = U @ np.diag(s) @ Vt
np.allclose(X, X_rec)  # True

# усечённое SVD — приближение ранга k
k = 1
X_approx = U[:, :k] @ np.diag(s[:k]) @ Vt[:k, :]
```

Связь с `eig`: правые сингулярные векторы (`Vt.T`) — это собственные векторы $X^T X$, а $\sigma_j^2$ — их собственные значения. Использовать `svd` напрямую предпочтительнее, чем `eig(X.T @ X)`, — численно устойчивее.

Для разреженных матриц (текст, рекомендации) — `sklearn.decomposition.TruncatedSVD`, которая не требует dense матрицы.
