# np.dot

- скалярное произведение векторов, матричное умножение или свёртка осей;
- конкретное поведение зависит от размерности аргументов.

```python
np.dot(a, b, out=None)
```

- `a`, `b` — обязательные аргументы без значений по умолчанию;
- `out=None` — массив для записи результата. Если он передан, его форма и
  dtype должны точно совпадать с результатом, а память должна быть C-contiguous.

Правила работы:

| Форма `a` | Форма `b` | Результат |
|---|---|---|
| `()` | любая | умножение, как `a * b` |
| любая | `()` | умножение, как `a * b` |
| `(k,)` | `(k,)` | скалярное произведение, shape `()` |
| `(m, k)` | `(k, n)` | матричное умножение, shape `(m, n)` |
| `(..., k)` | `(k,)` | свёртка последних осей, shape `(...)` |
| `(..., k)` | `(..., k, n)` | свёртка последней оси `a` и предпоследней оси `b` |

В общем случае форма результата вычисляется так:

```python
a.shape[:-1] + b.shape[:-2] + (b.shape[-1],)
```

Скалярное произведение двух векторов:

```python
import numpy as np

# Начальные значения аргументов
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

result = np.dot(a, b)

print(result)        # 32
print(result.shape)  # ()
```

Для двух матриц `np.dot` ведёт себя так же, как `@`:

```python
# Начальные значения аргументов
a = np.array([
    [1, 2, 3],
    [4, 5, 6],
])

b = np.array([
    [1, 2],
    [3, 4],
    [5, 6],
])

result = np.dot(a, b)

print(result)
# [[22 28]
#  [49 64]]
```

Для массивов размерности больше двух `np.dot` не выполняет пакетное
матричное умножение. Несворачиваемые оси обоих аргументов сохраняются:

```python
# Начальные значения аргументов
a = np.zeros((2, 3, 4))
b = np.zeros((2, 4, 5))

print(np.dot(a, b).shape)  # (2, 3, 2, 5)
print((a @ b).shape)       # (2, 3, 5)
```

В случае `2D dot 3D` порядок осей также может оказаться неожиданным:

```python
# Начальные значения аргументов
a = np.zeros((3, 4))
b = np.zeros((2, 4, 5))

print(np.dot(a, b).shape)  # (3, 2, 5)
print((a @ b).shape)       # (2, 3, 5)
```

# np.logaddexp

- вычисляет `log(exp(x1) + exp(x2))` численно устойчивым способом;
- применяет broadcasting и работает поэлементно.

```python
np.logaddexp(x1, x2)
```

Прямое вычисление может переполниться, хотя итоговый логарифм представим:

```python
import numpy as np

x1 = 1000.0
x2 = 1000.0

# np.log(np.exp(x1) + np.exp(x2))  # inf из-за переполнения exp
np.logaddexp(x1, x2)               # 1000.693147...
```

Устойчивое вычисление логистической функции потерь
`log(1 + exp(-margin))`:

```python
margin = np.array([1000.0, 0.0, -1000.0])
loss = np.logaddexp(0, -margin)
# [   0.            0.69314718 1000.        ]
```

# np.matmul и оператор `@`

- матричное и пакетное матричное умножение;
- для массивов NumPy выражение `a @ b` эквивалентно `np.matmul(a, b)`;
- в отличие от `a * b`, это не поэлементное умножение.

Основная сигнатура:

```python
np.matmul(
    x1,
    x2,
    out=None,
    *,
    casting="same_kind",
    order="K",
    dtype=None,
    subok=True,
)
```

- `x1`, `x2` — обязательные аргументы без значений по умолчанию;
- `out=None` — массив для записи результата;
- `casting="same_kind"` — разрешает безопасные преобразования внутри одной
  группы типов, например `float32` в `float64`;
- `order="K"` — по возможности сохраняет порядок расположения данных в памяти;
- `dtype=None` — тип результата определяется по входным аргументам;
- `subok=True` — сохраняет подклассы `ndarray`;
- `signature`, `axes`, `axis` — дополнительные необязательные параметры
  generalized ufunc; в обычном матричном умножении почти не используются.

Правила размерностей:

| Форма `x1` | Форма `x2` | Результат |
|---|---|---|
| `(k,)` | `(k,)` | скаляр, shape `()` |
| `(m, k)` | `(k,)` | `(m,)` |
| `(k,)` | `(k, n)` | `(n,)` |
| `(m, k)` | `(k, n)` | `(m, n)` |
| `(..., m, k)` | `(k,)` | `(..., m)` |
| `(k,)` | `(..., k, n)` | `(..., n)` |
| `(..., m, k)` | `(..., k, n)` | `(..., m, n)` |

Обычное матричное умножение:

```python
import numpy as np

# Начальные значения аргументов
a = np.array([
    [1, 2, 3],
    [4, 5, 6],
])                         # shape: (2, 3)

b = np.array([
    [1, 2],
    [3, 4],
    [5, 6],
])                         # shape: (3, 2)

result = a @ b             # то же самое, что np.matmul(a, b)

print(result)
# [[22 28]
#  [49 64]]
print(result.shape)         # (2, 2)
```

Начальные, или пакетные, оси растягиваются по правилам broadcasting. Последние
две оси считаются матричными и не растягиваются:

```python
# Начальные значения аргументов
a = np.zeros((10, 3, 4))   # 10 матриц 3 x 4
b = np.zeros((1, 4, 5))    # одна матрица 4 x 5

print((a @ b).shape)       # (10, 3, 5)

b_wrong = np.zeros((10, 6, 5))
# a @ b_wrong              # ValueError: 4 и 6 не совпадают
```

Скалярное произведение одномерных массивов возвращает скаляр:

```python
# Начальные значения аргументов
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

result = a @ b

print(result)              # 32
print(result.shape)        # ()
```

## `.T` не превращает 1D-массив в столбец

У одномерного массива только одна ось, поэтому транспонировать нечего:

```python
# Начальное значение
x = np.array([1, 2, 3])

print(x.shape)             # (3,)
print(x.T.shape)           # (3,) — форма не изменилась

column = x[:, np.newaxis]  # или x.reshape(-1, 1)
row = x[np.newaxis, :]     # или x.reshape(1, -1)

print(column.shape)        # (3, 1)
print(row.shape)           # (1, 3)
print((column @ row).shape)  # (3, 3)
print((row @ column).shape)  # (1, 1)
```

## Подводные камни

- Скаляры использовать нельзя: `a @ 2` и `np.matmul(a, 2)` вызывают
  `ValueError`. Для умножения на число нужен оператор `*`.
- Обычные списки не реализуют `@`: `[1, 2] @ [3, 4]` вызывает `TypeError`,
  но `np.matmul([1, 2], [3, 4])` возвращает `11`.
- Цепочка `a @ b @ c` вычисляется слева направо как `(a @ b) @ c`.
  `np.linalg.multi_dot` может выбрать более выгодный порядок умножения.
- При целочисленном умножении возможно переполнение без исключения. Нужно
  заранее выбрать dtype с достаточным диапазоном.
- Класс `np.matrix` меняет смысл `*` на матричное умножение. В новом коде
  лучше использовать `ndarray`, `*` и `@`.

# np.polyval

- для работы с полиномами.

```python
import numpy as np

# Коэффициенты полинома: [a_n, a_{n-1}, ..., a_1, a_0]
# для a_n*x^n + ... + a_0
coefficients = [2, -3, 1]  # 2x² - 3x + 1

# Точки x, в которых нужно вычислить полином
x_values = [0, 1, 2, 3]

y_values = np.polyval(coefficients, x_values)
y_1 = np.polyval(coefficients, 1)

print(y_values)  # [1, 0, 3, 10]
print(y_1)       # 0 — значение полинома в точке 1
```

# np.power

- возведение в степень.

```python
import numpy as np

print(np.power(2, 3))  # 2³ = 8

arr = np.array([1, 2, 3])
print(np.power(arr, 2))  # [1, 4, 9]

a = np.array([2, 3, 4])
b = np.array([3, 2, 1])

np.power(a, b)  # [8, 9, 4]

# Целое число нельзя возвести в отрицательную целую степень
# np.power(2, -2)  # ValueError
np.power(2.0, -2)  # 0.25
```

Степени растягиваются по правилам broadcasting:

```python
a = np.array([
    [1, 2],
    [3, 4],
])

b = np.array([2, 3])

np.power(a, b)
# [[ 1,  8],
#  [ 9, 64]]
```

# np.vdot

- скалярное произведение после преобразования обоих аргументов в 1D;
- для комплексных чисел первый аргумент комплексно сопрягается.

```python
np.vdot(a, b)
```

- `a`, `b` — обязательные аргументы без значений по умолчанию.

`np.dot` и `@` не выполняют комплексное сопряжение:

```python
import numpy as np

# Начальные значения аргументов
a = np.array([1j])
b = np.array([1j])

print(np.dot(a, b))   # -1+0j: 1j * 1j
print(a @ b)          # -1+0j
print(np.vdot(a, b))  #  1+0j: conj(1j) * 1j
```

# np.where

- выбирает элементы из двух массивов по условию;
- при одном аргументе возвращает индексы элементов, для которых условие истинно.

```python
np.where(condition, x, y)
np.where(condition)
```

`x` выбирается там, где условие истинно, иначе выбирается `y`. Все три
аргумента растягиваются по правилам broadcasting:

```python
import numpy as np

scores = np.array([-2.0, 0.0, 3.5])
labels = np.where(scores >= 0, 1, -1)

print(labels)  # [-1  1  1]
```

Получение индексов:

```python
x = np.array([10, -5, 20, -1])
indices = np.where(x > 0)

print(indices)     # (array([0, 2]),)
print(x[indices])  # [10 20]
```
