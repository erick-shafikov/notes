# Пирамидальная сортировка (сортировка кучей)

Максимальная двоичная куча — дерево, где родитель не меньше детей. В массиве дети узла `i` имеют индексы `2i + 1` и `2i + 2`. Корень содержит максимум, но весь массив кучи ещё не отсортирован.

Строим кучу, меняем корень с последним элементом активной части, уменьшаем кучу и восстанавливаем её просеиванием вниз.

```ts
function heapSort(a: number[]): number[] {
  function siftDown(root: number, size: number): void {
    while (root * 2 + 1 < size) {
      let child = root * 2 + 1;
      if (child + 1 < size && a[child + 1] > a[child]) child++;
      if (a[root] >= a[child]) return;
      [a[root], a[child]] = [a[child], a[root]];
      root = child;
    }
  }

  // Листья уже являются кучами; начинаем с последнего родителя.
  for (let i = Math.floor(a.length / 2) - 1; i >= 0; i--) {
    siftDown(i, a.length);
  }
  for (let end = a.length - 1; end > 0; end--) {
    [a[0], a[end]] = [a[end], a[0]];
    siftDown(0, end); // Элемент end уже исключён из кучи.
  }
  return a;
}

console.log(heapSort([4, 10, 3, 5, 1])); // [1, 3, 4, 5, 10]
```

Построение снизу вверх занимает `O(n)`: большинство узлов находятся близко к листьям. Извлечения дают худшее и среднее время `O(n log n)`. На одинаковых элементах эта реализация работает за `O(n)`, поскольку просеивание сразу завершается. Дополнительная память `O(1)`, массив изменяется, сортировка неустойчива. Полезна, если нужны гарантированная верхняя граница `O(n log n)` и постоянная дополнительная память.
