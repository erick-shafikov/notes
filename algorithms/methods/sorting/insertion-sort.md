# Сортировка вставками

Поддерживаем отсортированный префикс. Очередное значение запоминаем, сдвигаем большие элементы вправо и вставляем значение в освободившееся место.

Для `[3, 1, 2]`: вставляем 1 в `[3]` и получаем `[1, 3, 2]`; затем вставляем 2 между 1 и 3.

```ts
function insertionSort(a: number[]): number[] {
  for (let i = 1; i < a.length; i++) {
    const value = a[i];
    let j = i - 1;
    while (j >= 0 && a[j] > value) {
      a[j + 1] = a[j]; // Сдвиг, а не потеря текущего value.
      j--;
    }
    a[j + 1] = value;
  }
  return a;
}

console.log(insertionSort([3, -1, 2, 2])); // [-1, 2, 2, 3]
```

Изменяет массив. Устойчива благодаря строгому сравнению `>`: равный элемент остаётся перед вставляемым. Лучшее время `O(n)`, среднее и худшее `O(n²)`, память `O(1)`. Хороша для небольших и почти отсортированных массивов; число сдвигов равно числу инверсий.
