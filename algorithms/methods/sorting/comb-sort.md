# Сортировка расчёской

Сначала сравнивает элементы на большом расстоянии `gap`, затем уменьшает его примерно в 1,3 раза. Большие шаги быстро перемещают маленькие элементы из конца в начало. При шаге 1 продолжаются обычные пузырьковые проходы до исчезновения обменов.

```ts
function combSort(a: number[]): number[] {
  let gap = a.length;
  let swapped = true;
  while (gap > 1 || swapped) {
    gap = Math.max(1, Math.floor(gap / 1.3));
    swapped = false;
    for (let i = 0; i + gap < a.length; i++) {
      if (a[i] > a[i + gap]) {
        [a[i], a[i + gap]] = [a[i + gap], a[i]];
        swapped = true;
      }
    }
  }
  return a;
}

console.log(combSort([8, 4, 1, 3, 1])); // [1, 1, 3, 4, 8]
```

Для пяти элементов шаги: `3 → 2 → 1`. Одного прохода с шагом 1 недостаточно: выход разрешён только при отсутствии обменов.

Изменяет массив, неустойчива из-за дальних обменов. Дополнительная память `O(1)`, худшее время `O(n²)`, лучшее для этой реализации `O(n log n)` из-за последовательности шагов. Среднее время зависит от распределения данных и выбора шагов; гарантии `O(n log n)` нет.
