# Сортировки и строковые алгоритмы

Все примеры оформлены как самостоятельные блоки TypeScript в Markdown. Числовые сортировки упорядочивают по возрастанию. Если не указано иное, вход — конечные числа без `NaN` и бесконечностей; подсчёт и поразрядная сортировка имеют более строгие ограничения. Пустые массивы и дубликаты поддерживаются.

Устойчивость означает сохранение взаимного порядка элементов с равными ключами. На одних числах это незаметно, но существенно при сортировке записей. Память в таблице — пиковая дополнительная, включая результат и стек.

| Конспект | Время: лучшее / среднее / худшее | Память | Устойчивость | Изменяет вход |
| --- | --- | --- | --- | --- |
| [Шейкерная](shaker-sort.md) | O(n) / O(n²) / O(n²) | O(1) | да | да |
| [Расчёской](comb-sort.md) | O(n log n) / зависит от данных / O(n²) | O(1) | нет | да |
| [Вставками](insertion-sort.md) | O(n) / O(n²) / O(n²) | O(1) | да | да |
| [Выбором](selection-sort.md) | O(n²) во всех случаях | O(1) | нет | да |
| [Выбором, рекурсивно](selection-recursive.md) | O(n²) во всех случаях | O(n) | да | нет |
| [Слиянием](merge-sort.md) | O(n log n) во всех случаях | O(n) | да | нет |
| [Быстрая, Ломуто](quick-sort.md) | O(n log n) / O(n log n) / O(n²) | O(log n) в среднем, O(n) в худшем | нет | да |
| [Пирамидальная](heap-sort.md) | O(n) на равных / O(n log n) / O(n log n) | O(1) | нет | да |
| [Подсчётом](counting-sort.md) | O(n + k) | O(n + k) | да | нет |
| [Поразрядная](radix-sort.md) | O(n + d(n + b)) | O(n + b) | да | нет |
| [Блочная](bucket-sort.md) | O(n) / ожидаемо O(n) / O(n²) | O(n) при k = n | да | нет |
| [Циклическая](cycle.md) | O(n²) во всех случаях | O(1) | нет | да |

`n` — количество элементов; для подсчёта `k` — диапазон ключей, для блочной сортировки — число корзин; `d` — количество разрядов, `b` — основание. Ожидаемая линейность блочной сортировки требует равномерного распределения. Среднее время быстрой сортировки Ломуто указано для случайного порядка входа. Свойства относятся именно к приведённым реализациям; дополнительные варианты описаны в соответствующих файлах.

Нижняя граница `Ω(n log n)` в худшем случае относится к общим сортировкам сравнениями. Подсчёт и поразрядная сортировка используют структуру ключей и не противоречат этой границе.
