# Пузырьковая сортировка

Проходим по массиву и сравниваем соседние элементы: если левый больше правого, меняем их местами. За один проход максимум «всплывает» в конец неотсортированной части, поэтому каждый следующий проход короче на один элемент.

Для `[3, 1, 2]`: первый проход даёт `[1, 2, 3]`, второй проход обменов не находит — массив отсортирован.

```ts
function bubbleSort(a: number[]): number[] {
  for (let end = a.length - 1; end > 0; end--) {
    let swapped = false;
    for (let i = 0; i < end; i++) {
      if (a[i] > a[i + 1]) {
        [a[i], a[i + 1]] = [a[i + 1], a[i]];
        swapped = true;
      }
    }
    if (!swapped) break;
  }
  return a;
}

console.log(bubbleSort([5, 3, 6, 2, 10, 3])); // [2, 3, 3, 5, 6, 10]
```

Изменяет исходный массив. Устойчива: равные соседи не меняются местами, так как сравнение строгое. Лучшее время `O(n)` на уже отсортированном массиве благодаря флагу `swapped`, среднее и худшее `O(n²)`, дополнительная память `O(1)`.

Без флага `swapped` сортировка всегда делает `O(n²)` сравнений. Внутренний цикл должен идти до `end`, а не до `a.length - i`: иначе на последней итерации сравнивается `a[i]` с несуществующим `a[i + 1]`.

Улучшения: [шейкерная сортировка](shaker-sort.md) проходит в обе стороны и быстрее переносит маленькие элементы в начало, [сортировка расчёской](comb-sort.md) сначала сравнивает элементы на большом расстоянии.
