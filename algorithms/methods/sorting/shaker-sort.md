# Шейкерная сортировка

Двунаправленный вариант пузырьковой сортировки: проход слева направо переносит максимум вправо, обратный проход — минимум влево. После каждого прохода граница неотсортированной части сужается.

Для `[3, 2, 1]`: прямой проход даёт `[2, 1, 3]`, обратный — `[1, 2, 3]`. Если обменов нет, массив уже отсортирован.

```ts
function shakerSort(a: number[]): number[] {
  let left = 0;
  let right = a.length - 1;
  while (left < right) {
    let swapped = false;
    for (let i = left; i < right; i++) {
      if (a[i] > a[i + 1]) {
        [a[i], a[i + 1]] = [a[i + 1], a[i]];
        swapped = true;
      }
    }
    if (!swapped) break;
    right--; // Максимум уже на своём месте.
    swapped = false;
    for (let i = right; i > left; i--) {
      if (a[i - 1] > a[i]) {
        [a[i - 1], a[i]] = [a[i], a[i - 1]];
        swapped = true;
      }
    }
    left++;
    if (!swapped) break;
  }
  return a;
}

console.log(shakerSort([3, 2, 1, 2])); // [1, 2, 2, 3]
```

Изменяет исходный массив. Устойчива: равные элементы не меняются местами. Лучшее время `O(n)`, среднее и худшее `O(n²)`, дополнительная память `O(1)`. Подходит для обучения и небольших почти упорядоченных массивов.
