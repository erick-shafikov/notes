# Синтаксис

- Идентификаторы (имена) - то к чему обращаются. Названия строк, таблиц и так далее. Максимальный размер 1 байт
- - что бы назвать идентификатор именем команды его нужно взять в кавычки "select", это позволяет создавать имена с пробелами
- - поддержка unicode 'U&"d\0061t\+000061"'
- - спецсимволы 'U&"d!0061t!+000061" UESCAPE '!''
- - для строк со множественными апострофами '$$Жанна д'Арк$$
- Команды - операции над идентификаторами

три типа констант подразумеваемых типов:

- строки - 'Это строка'

  ```sql
  SELECT 'foo'
  'bar';
  -- Тоже самое что и
  SELECT 'foobar';
  ```

- битовые строки - X'1FF'
- числа
- ввод константы собственного типа

  ```sql
  type 'string'
  'string'::type
  CAST ( 'string' AS type )
  -- или
  typename ( 'string' )

  ```

# операторы

+ - * / < > = ~ ! @ # % ^ & | ` ?
