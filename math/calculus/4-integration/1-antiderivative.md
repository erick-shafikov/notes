Функция $F: (a, b) \to \mathbb{R}$ называется **первообразной** функции $f: (a, b) \to \mathbb{R}$, если $F$ дифференцируема на $(a, b)$ и $F'(x) = f(x)$ для всех $x \in (a, b)$.

Не каждая функция имеет первообразную. Например, $f(x) = \begin{cases} -1, & x \in [-1, 0] \\ 1, & x \in (0, 1) \end{cases}$ — разрывная функция без первообразной: если бы $F' = f$, то по теореме Дарбу $F'$ принимала бы все промежуточные значения, в частности $0$, — противоречие. Напротив, каждая непрерывная функция на $(a, b)$ имеет первообразную (теорема Барроу, см. [формулу Ньютона-Лейбница](4-newton-leibniz.md)).

**Неопределённый интеграл** — это множество всех первообразных функции $f$:

$$\int f(x)\,dx = F(x) + C,$$

где $C$ пробегает все вещественные числа. Поскольку разность двух первообразных одной функции постоянна (следствие теоремы Лагранжа), $\int f(x)\,dx$ есть в точности сдвиг одной первообразной на произвольную константу.

Удобно думать о неопределённом интеграле как о классе (множестве) функций. Если $A = \int f(x)\,dx$ и $B = \int g(x)\,dx$ — такие классы, то действия с ними определяются поэлементно:

$$A + B = \{h + k : h \in A,\, k \in B\}, \qquad \lambda A = \{\lambda h : h \in A\}, \qquad A + h_0 = \{h + h_0 : h \in A\}$$

для фиксированной функции $h_0$. В этих обозначениях $(A)' = \{h' : h \in A\}$ и $\int f(x)\,dx = \{F\}$ означает, что класс состоит из всех сдвигов $F$ на константу.

Линейность интеграла: если $F$ и $G$ — первообразные $f$ и $g$ соответственно, то

$$\int f(x)\,dx + \int g(x)\,dx = \{F(x) + G(x) + C : C \in \mathbb{R}\},$$

$$\int \lambda f(x)\,dx = \lambda F(x) + C, \qquad \int f(x)\,dx + h(x) = \{F(x) + h(x) + C : C \in \mathbb{R}\}.$$

Таблица стандартных первообразных: $\int x^n\,dx = \dfrac{x^{n+1}}{n+1} + C$ ($n \neq -1$), $\int \dfrac{dx}{x} = \ln|x| + C$, $\int e^x\,dx = e^x + C$, $\int \sin x\,dx = -\cos x + C$, $\int \cos x\,dx = \sin x + C$.
