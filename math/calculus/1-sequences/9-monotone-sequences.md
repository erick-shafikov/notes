**Теорема.** Всякая возрастающая и ограниченная сверху последовательность сходится.

*Доказательство.* Пусть $\{x_n\}$ возрастает и ограничена сверху. Рассмотрим множество $E = \{x_1, x_2, x_3, \ldots\}$. Оно непусто и ограничено сверху, поэтому по [теореме о существовании супремума](8-real-numbers.md) существует $c = \sup E$.

Покажем, что $\lim_{n\to\infty} x_n = c$. Для любого $\varepsilon > 0$ из определения супремума следует, что $c - \varepsilon$ уже не является верхней гранью, то есть найдётся номер $N$ такой, что

$$x_N > c - \varepsilon$$

При всех $n \geq N$ выполнены оба условия:

а) $x_n < c + \varepsilon$, поскольку $x_n \leq c < c + \varepsilon$ (c — верхняя грань E);

б) $x_n \geq x_N > c - \varepsilon$, поскольку последовательность возрастает.

Следовательно, $x_n \in (c - \varepsilon,\, c + \varepsilon)$ при всех $n \geq N$, то есть $|x_n - c| < \varepsilon$. Таким образом, $\lim_{n\to\infty} x_n = c = \sup E$.

Аналогичная теорема: всякая убывающая и ограниченная снизу последовательность сходится к своему инфимуму.
