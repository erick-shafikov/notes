Рассматриваем ряды с положительными членами: $a_n > 0$.

**Признак Даламбера (основная форма).** Если начиная с некоторого $N$ выполнено $\frac{a_{n+1}}{a_n} \leq q < 1$, то $\sum a_n$ сходится. Если $\frac{a_{n+1}}{a_n} \geq 1$ для всех $n \geq N$, то $\sum a_n$ расходится (так как $a_n \not\to 0$).

**Признак Даламбера (предельная форма).** Пусть существует $\lim_{n\to\infty} \frac{a_{n+1}}{a_n} = q^*$. Тогда:

* $q^* < 1$ — ряд сходится;
* $q^* > 1$ — ряд расходится;
* $q^* = 1$ — вывод сделать нельзя.

**Признак Коши (радикальный).** Пусть существует $\lim_{n\to\infty} \sqrt[n]{a_n} = q^*$. Выводы те же:

* $q^* < 1$ — ряд сходится;
* $q^* > 1$ — ряд расходится;
* $q^* = 1$ — вывод сделать нельзя.

**Связь признаков.** Если существует $\lim_{n\to\infty} \frac{a_{n+1}}{a_n} = a^*$, то существует и $\lim_{n\to\infty} \sqrt[n]{a_n} = a^*$. Таким образом, признак Даламбера — более сильный инструмент: из его применимости следует применимость признака Коши, но не наоборот.

**Пример.** $a_n = \frac{b^n}{n!}$, $b > 0$:

$$\frac{a_{n+1}}{a_n} = \frac{b^{n+1}}{(n+1)!} \cdot \frac{n!}{b^n} = \frac{b}{n+1} \xrightarrow{n\to\infty} 0 < 1$$

Ряд $\sum \frac{b^n}{n!}$ сходится при любом $b > 0$.

**Пример, где $q^* = 1$.** Для $a_n = \frac{1}{n^2}$: $\frac{a_{n+1}}{a_n} = \frac{n^2}{(n+1)^2} \to 1$ — признак Даламбера не даёт вывода. Сходимость $\sum \frac{1}{n^2}$ устанавливается теоремой сравнения (сравнение с $\sum \frac{1}{n(n-1)}$, телескопической суммой).
