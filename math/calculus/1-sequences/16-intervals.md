## Отрезки, интервалы, полуинтервалы

Для $a, b \in \mathbb{R}$, $a < b$, определяются следующие подмножества числовой прямой:

| Обозначение | Определение | Название |
|---|---|---|
| $[a, b]$ | $\{x \in \mathbb{R} \mid a \leq x \leq b\}$ | отрезок (замкнутый промежуток) |
| $(a, b)$ | $\{x \in \mathbb{R} \mid a < x < b\}$ | интервал (открытый промежуток) |
| $[a, b)$ | $\{x \in \mathbb{R} \mid a \leq x < b\}$ | полуинтервал |
| $(a, b]$ | $\{x \in \mathbb{R} \mid a < x \leq b\}$ | полуинтервал |

Бесконечные промежутки:

$$(-\infty, b] = \{x \in \mathbb{R} \mid x \leq b\}, \quad [a, +\infty) = \{x \in \mathbb{R} \mid x \geq a\}$$
$$(a, +\infty) = \{x \in \mathbb{R} \mid x > a\}, \quad (-\infty, b) = \{x \in \mathbb{R} \mid x < b\}$$

Вся числовая прямая: $(-\infty, +\infty) = \mathbb{R}$.

**Окрестность точки.** $\delta$-окрестность точки $a$ — интервал $(a - \delta,\; a + \delta)$; записывают $U_\delta(a)$ или $B(a, \delta)$.

Проколотая окрестность (без самой точки): $\mathring{U}_\delta(a) = (a-\delta, a) \cup (a, a+\delta)$.
