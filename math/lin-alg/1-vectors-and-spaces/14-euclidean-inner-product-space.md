**Евклидово пространство.** Вещественное векторное пространство $V$ называется евклидовым, если на нём задано скалярное произведение — функция $(x, y)$ двух векторов, принимающая вещественные значения и удовлетворяющая четырём аксиомам:

1. $(x, y) = (y, x)$ (симметричность);
2. $(\lambda x, y) = \lambda(x, y)$ для любого $\lambda \in \mathbb{R}$ (однородность);
3. $(x_1 + x_2, y) = (x_1, y) + (x_2, y)$ (линейность по первому аргументу);
4. $(x, x) \geq 0$, причём $(x, x) = 0 \Leftrightarrow x = 0$ (положительная определённость).

Из аксиом 1–3 следует, что скалярное произведение билинейно: линейно по каждому аргументу.

**Матричная форма скалярного произведения.** Пусть $V = \mathbb{R}^n$ и $x$, $y$ имеют координаты $(\xi_1, \ldots, \xi_n)$ и $(\eta_1, \ldots, \eta_n)$ в некотором базисе. Любое билинейное скалярное произведение записывается через матрицу Грама $A = (a_{ij})$:

$$(x, y) = \sum_{i,j=1}^{n} a_{ij}\,\xi_i\,\eta_j = \xi^T A \eta.$$

Чтобы аксиомы выполнялись, необходимо: $a_{ij} = a_{ji}$ (симметричность, обеспечивает аксиому 1) и $\sum_{i,j} a_{ij}\xi_i\xi_j \geq 0$ с равенством нулю лишь при $\xi = 0$ (положительная определённость, аксиома 4). Стандартное скалярное произведение соответствует $A = I$:

$$(x, y) = \xi_1\eta_1 + \xi_2\eta_2 + \cdots + \xi_n\eta_n.$$

**Пример бесконечномерного евклидова пространства.** На пространстве $C[a,b]$ непрерывных функций скалярное произведение задаётся интегралом:

$$(f, g) = \int_a^b f(x)\,g(x)\,dx.$$

Все четыре аксиомы выполнены; в частности, $(f,f) = \int_a^b f(x)^2\,dx \geq 0$ обращается в нуль тогда и только тогда, когда $f \equiv 0$.

**Норма.** В евклидовом пространстве длина вектора определяется через скалярное произведение: $\|x\| = \sqrt{(x,x)}$.

**Неравенство Коши–Буняковского.** В любом евклидовом пространстве для всех $x, y \in V$:

$$(x, y)^2 \leq (x, x)(y, y).$$

Доказательство: рассмотрим $\varphi(t) = (x - ty,\, x - ty) \geq 0$ для всех $t \in \mathbb{R}$. Раскрывая по билинейности:

$$\varphi(t) = (x, x) - 2t(x, y) + t^2(y, y) \geq 0.$$

Это квадратный трёхчлен по $t$, неотрицательный при всех $t$, значит его дискриминант не положителен:

$$4(x,y)^2 - 4(x,x)(y,y) \leq 0,$$

что и даёт неравенство. Следствие: выражение $(x,y)/(\|x\|\cdot\|y\|)$ лежит в $[-1, 1]$ и, таким образом, является косинусом некоторого угла.
