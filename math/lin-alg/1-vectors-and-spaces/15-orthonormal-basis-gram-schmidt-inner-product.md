**Ортонормированный базис евклидова пространства.** В евклидовом пространстве $V$ базис $\{e_1, e_2, \ldots, e_n\}$ называется ортонормированным, если

$$(e_i, e_k) = \begin{cases} 0, & i \neq k, \\ 1, & i = k. \end{cases}$$

Такой набор всегда линейно независим (из $(x,x)=0 \Leftrightarrow x=0$) и при $n$ векторах в $n$-мерном пространстве образует базис.

**Координаты в ортонормированном базисе.** Если $\{e_1, \ldots, e_n\}$ — ортонормированный базис и $x = \xi^1 e_1 + \cdots + \xi^n e_n$, то координата $\xi^k$ находится через скалярное произведение:

$$\xi^k = (x, e_k).$$

Это следует из того, что $(x, e_k) = \xi^1(e_1, e_k) + \cdots + \xi^n(e_n, e_k) = \xi^k$, поскольку все остальные слагаемые обнуляются по ортогональности. Скалярное произведение двух векторов в ортонормированном базисе принимает вид:

$$(x, y) = \sum_{k=1}^n \xi^k \eta^k,$$

где $\xi^k = (x, e_k)$, $\eta^k = (y, e_k)$ — координаты $x$ и $y$ соответственно. В обычном нескалярном (неортонормированном) базисе координаты из этой формулы не следовали бы: пришлось бы решать систему $(x, e_k) = \sum_j \xi^j(e_j, e_k)$.

**Проекция на подпространство.** Пусть $\{e_1, \ldots, e_m\}$ — ортонормированный базис подпространства $W \subset V$ и $x_0 = \xi^1 e_1 + \cdots + \xi^m e_m$ — проекция вектора $x$ на $W$. Остаток $h = x - x_0$ ортогонален $W$: $(h, e_k) = 0$ для всех $k = 1,\ldots,m$. Из этого условия:

$$0 = (x - x_0,\, e_k) = (x, e_k) - \xi^k \quad \Rightarrow \quad \xi^k = (x, e_k),$$

и потому $x_0 = \sum_{k=1}^m (x, e_k)\,e_k$.

**Метод Грама–Шмидта в евклидовом пространстве.** По произвольному базису $\{f_1, f_2, \ldots, f_n\}$ строится ортогональный базис $\{e_1, e_2, \ldots, e_n\}$ того же подпространства.

**Шаг 1.** $e_1 = f_1$.

**Шаг 2.** Ищем $e_2 = f_2 + \alpha e_1$ так, чтобы $(e_1, e_2) = 0$:

$$(e_1,\, f_2 + \alpha e_1) = 0 \;\Rightarrow\; (e_1, f_2) + \alpha(e_1, e_1) = 0 \;\Rightarrow\; \alpha = -\frac{(e_1, f_2)}{(e_1, e_1)}.$$

Тогда $e_2 = f_2 - \dfrac{(e_1, f_2)}{(e_1, e_1)}\,e_1$.

**Шаг 3.** Ищем $e_3 = f_3 + \beta_1 e_1 + \beta_2 e_2$, ортогональный к $e_1$ и $e_2$:

$$0 = (e_3, e_1) = (f_3, e_1) + \beta_1(e_1, e_1) \;\Rightarrow\; \beta_1 = -\frac{(f_3, e_1)}{(e_1, e_1)},$$

$$0 = (e_3, e_2) = (f_3, e_2) + \beta_2(e_2, e_2) \;\Rightarrow\; \beta_2 = -\frac{(f_3, e_2)}{(e_2, e_2)}.$$

**Общий шаг $k$.** Вычитаем из $f_k$ проекции на все ранее построенные ортогональные векторы:

$$e_k = f_k - \sum_{j=1}^{k-1} \frac{(f_k, e_j)}{(e_j, e_j)}\,e_j.$$

При желании получить ортонормированный базис нормируем: $\hat{e}_k = e_k / \sqrt{(e_k, e_k)}$.
