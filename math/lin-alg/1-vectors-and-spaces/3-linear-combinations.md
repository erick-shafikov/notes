**Линейная комбинация** векторов $v_1, \ldots, v_n$ — любой вектор вида $c_1 v_1 + \cdots + c_n v_n$, где $c_i \in \mathbb{R}$. Множество всех таких комбинаций называется **линейной оболочкой** (span):

$$\operatorname{span}(v_1, \ldots, v_n) = \{c_1 v_1 + \cdots + c_n v_n \mid c_i \in \mathbb{R}\}.$$

Стандартные базисные векторы $\vec{i}=(1,0)$ и $\vec{j}=(0,1)$ порождают всё $\mathbb{R}^2$: любой вектор $(x,y)=x\vec{i}+y\vec{j}$.

**Линейная зависимость.** Набор $\{v_1, \ldots, v_n\}$ называется **линейно зависимым**, если система $c_1 v_1 + \cdots + c_n v_n = \vec{0}$ имеет нетривиальное решение (не все $c_i=0$). В противном случае набор **линейно независим**.

Пример: $\left\{\begin{bmatrix}2\\1\end{bmatrix}, \begin{bmatrix}3\\2\end{bmatrix}\right\}$ — линейно независимы (единственное решение $c_1=c_2=0$). Добавим третий вектор $\begin{bmatrix}1\\2\end{bmatrix}$: система $2c_1+3c_2+c_3=0$, $c_1+2c_2+2c_3=0$ имеет нетривиальное решение при $c_3=-1$, значит, тройка **линейно зависима**.

Пример в $\mathbb{R}^3$: пусть $a=\begin{bmatrix}1\\2\\2\end{bmatrix}$, $b=\begin{bmatrix}3\\1\\3\end{bmatrix}$, $c=\begin{bmatrix}2\\0\\2\end{bmatrix}$. Составив систему для произвольного вектора, можно показать, что любой вектор из $\mathbb{R}^3$ выражается через $a, b, c$ — следовательно, $\operatorname{span}(a,b,c)=\mathbb{R}^3$ и $\{a,b,c\}$ является базисом.
