**Ядро** (kernel) отображения $T: X \to Y$ — это прообраз нулевого элемента, то есть множество всех векторов, отображающихся в ноль:

$$\ker(T) = \{x \in X \mid T(x) = \vec{0}\}.$$

Для линейного преобразования $T(\vec{x}) = A\vec{x}$ ядро совпадает с нулевым пространством матрицы:

$$\ker(T) = N(A) = \{\vec{x} \in \mathbb{R}^n \mid A\vec{x} = \vec{0}\}.$$

**Пример.** Пусть $T: \mathbb{R}^2 \to \mathbb{R}^2$, $T(\vec{x}) = \begin{bmatrix}1&3\\2&6\end{bmatrix}\vec{x}$.

Система $A\vec{x} = \vec{0}$:

$$\begin{bmatrix}1&3\\2&6\end{bmatrix}\begin{bmatrix}x_1\\x_2\end{bmatrix} = \begin{bmatrix}0\\0\end{bmatrix} \;\Longrightarrow\; x_1 + 3x_2 = 0 \;\Longrightarrow\; x_1 = -3t,\ x_2 = t.$$

Ядро — прямая, параллельная вектору $(-3, 1)$:

$$\ker(T) = N(A) = \operatorname{span}\!\begin{pmatrix}-3\\1\end{pmatrix}.$$

Геометрически: все точки этой прямой «схлопываются» в ноль при применении $T$. Ядро всегда является подпространством области определения: нулевой вектор лежит в ядре ($A\vec{0}=\vec{0}$), и ядро замкнуто относительно сложения и умножения на скаляр — это следует непосредственно из линейности $T$.
