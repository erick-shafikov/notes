**Стандартная матрица** линейного преобразования $T: \mathbb{R}^n \to \mathbb{R}^m$ — это матрица $A = [T(e_1)\ T(e_2)\ \cdots\ T(e_n)]$, где $\{e_1, \ldots, e_n\}$ — стандартный базис $\mathbb{R}^n$.

Единичная матрица $I_n$ размера $n \times n$ удовлетворяет $I_n \vec{x} = \vec{x}$ и имеет столбцами ровно стандартные базисные векторы $e_1, \ldots, e_n$.

Для любого линейного $T$:

$$T(\vec{x}) = T(x_1 e_1 + \cdots + x_n e_n) = x_1 T(e_1) + \cdots + x_n T(e_n) = A\vec{x},$$

где $A$ — стандартная матрица. Таким образом, чтобы найти матрицу, достаточно вычислить образы базисных векторов и расставить их по столбцам.

**Пример.** Пусть $T: \mathbb{R}^2 \to \mathbb{R}^3$ задана формулой $T(x_1, x_2) = (x_1+3x_2,\ 5x_2-x_1,\ 4x_1+x_2)$. Вычислим:

$$T(e_1) = T\!\begin{pmatrix}1\\0\end{pmatrix} = \begin{pmatrix}1\\-1\\4\end{pmatrix}, \qquad T(e_2) = T\!\begin{pmatrix}0\\1\end{pmatrix} = \begin{pmatrix}3\\5\\1\end{pmatrix}.$$

Стандартная матрица:

$$A = \begin{bmatrix}1&3\\-1&5\\4&1\end{bmatrix}.$$

Проверка: $T(\vec{x}) = A\vec{x}$ воспроизводит исходную формулу для любого $\vec{x} \in \mathbb{R}^2$.
