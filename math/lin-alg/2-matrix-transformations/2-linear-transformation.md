**Линейное преобразование.** Отображение $T: \mathbb{R}^n \to \mathbb{R}^m$ называется линейным, если выполняются два условия:

1. $T(\vec{a} + \vec{b}) = T(\vec{a}) + T(\vec{b})$ для всех $\vec{a}, \vec{b} \in \mathbb{R}^n$,
2. $T(c\vec{a}) = cT(\vec{a})$ для всех $c \in \mathbb{R}$, $\vec{a} \in \mathbb{R}^n$.

**Пример нелинейного преобразования.** Пусть $T: \mathbb{R}^2 \to \mathbb{R}^2$, $T(x_1, x_2) = (x_1 + x_2 + 3, x_2)$. Проверим первое условие: $T(\vec{a} + \vec{b}) = (a_1+b_1+a_2+b_2+3, a_2+b_2)$, а $T(\vec{a})+T(\vec{b}) = (a_1+a_2+3+b_1+b_2+3, a_2+b_2)$. Эти выражения не равны из-за слагаемого $+3$, значит $T$ не является линейным.

**Пример линейного преобразования.** Пусть $T: \mathbb{R}^2 \to \mathbb{R}^2$, $T(\vec{x}) = B\vec{x}$, где $B = \begin{bmatrix}2&-1\\3&4\end{bmatrix}$. Тогда $T(x_1, x_2) = (2x_1-x_2,\ 3x_1+4x_2)$.

Проверим оба условия. Для сложения:

$$T(\vec{a}+\vec{b}) = B(\vec{a}+\vec{b}) = B\vec{a}+B\vec{b} = T(\vec{a})+T(\vec{b}).$$

Для умножения на скаляр:

$$T(c\vec{a}) = B(c\vec{a}) = cB\vec{a} = cT(\vec{a}).$$

Таким образом, матричное умножение $T(\vec{x}) = B\vec{x}$ всегда задаёт линейное преобразование. Это наблюдение является центральным: любое линейное преобразование $\mathbb{R}^n \to \mathbb{R}^m$ описывается умножением на матрицу размера $m \times n$.
