**Тождественное отображение** $I_X: X \to X$ определяется как $I_X(a) = a$ для всех $a \in X$.

**Обратная функция.** Отображение $f: X \to Y$ называется обратимым, если существует $f^{-1}: Y \to X$ такое, что $f^{-1} \circ f = I_X$, то есть $f^{-1}(f(x)) = x$ для всех $x \in X$. Обратная функция единственна.

**Критерий обратимости.** $f: X \to Y$ обратима тогда и только тогда, когда для каждого $y \in Y$ уравнение $f(x) = y$ имеет **единственное** решение. Это условие распадается на два:

- **Сюръективность** (surjective): $\forall y \in Y\ \exists x \in X: f(x) = y$ — «каждый элемент $Y$ достигается».
- **Инъективность** (injective): $\forall y \in Y$ существует не более одного $x$ с $f(x) = y$ — «функция сопоставляет $y$ не более чем одному $x$».

Отображение, обладающее обоими свойствами, называется **взаимно однозначным соответствием** (биекцией).

**Применение к линейным преобразованиям.** Для $T: \mathbb{R}^n \to \mathbb{R}^m$, $T(\vec{x}) = A\vec{x}$, обратимость означает:

- $T$ сюръективно $\Leftrightarrow$ система $A\vec{x} = \vec{b}$ совместна для любого $\vec{b}$ $\Leftrightarrow$ столбцы $A$ порождают все $\mathbb{R}^m$ $\Leftrightarrow$ $\operatorname{rank}(A) = m$.
- $T$ инъективно $\Leftrightarrow$ $N(A) = \{\vec{0}\}$ $\Leftrightarrow$ $A\vec{x} = \vec{0}$ имеет только тривиальное решение $\Leftrightarrow$ столбцы $A$ линейно независимы.

Для квадратной матрицы $A$ размера $n \times n$ обратимость $T$ равносильна существованию матрицы $A^{-1}$.
