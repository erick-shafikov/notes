## Пределы по направлению и предел по совокупности переменных

Пусть $f: E \to \mathbb{R}$, $E \subset \mathbb{R}^n$, $a$ — предельная точка $E$.

**Предел по совокупности переменных** (многомерный предел):

$$\lim_{x \to a} f(x) = L$$

означает: $\forall \varepsilon > 0\ \exists \delta > 0\ \forall x \in E,\; 0 < \|x - a\| < \delta \;\Rightarrow\; |f(x) - L| < \varepsilon.$

Здесь $x = (x_1, \ldots, x_n) \to a = (a_1, \ldots, a_n)$ по произвольным путям.

**Предел по направлению.** Для вектора $v \in \mathbb{R}^n$, $\|v\| = 1$:

$$\lim_{t \to 0^+} f(a + tv) = L_v$$

называется пределом по направлению $v$. Здесь точка движется вдоль луча из $a$ в направлении $v$.

**Отношение между пределами.**

- Если существует $\lim_{x \to a} f(x) = L$ (предел по совокупности), то для любого направления $v$ существует предел по направлению и равен $L$.
- Обратное неверно: существование и равенство всех пределов по направлениям не гарантирует существование предела по совокупности переменных.

**Пример (все направленные пределы совпадают, но предела по совокупности нет).**

$$f(x, y) = \frac{x^2 y}{x^4 + y^2}, \quad f(0, 0) = 0.$$

Вдоль любого направления $(t \cos\theta, t \sin\theta)$:

$$f(t\cos\theta, t\sin\theta) = \frac{t^3 \cos^2\theta \sin\theta}{t^4 \cos^4\theta + t^2 \sin^2\theta} = \frac{t \cos^2\theta \sin\theta}{t^2 \cos^4\theta + \sin^2\theta} \to 0 \text{ при } t \to 0.$$

Но вдоль параболы $y = x^2$:

$$f(t, t^2) = \frac{t^2 \cdot t^2}{t^4 + t^4} = \frac{t^4}{2t^4} = \frac{1}{2} \neq 0.$$

Следовательно, $\lim_{(x,y) \to (0,0)} f(x,y)$ не существует.

**Итог.** Для проверки существования предела по совокупности недостаточно проверять предел вдоль отдельных направлений — нужно проверить его вдоль всевозможных путей или использовать оценки.
