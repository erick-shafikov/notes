# Claude Code — инструкции для раздела fe/css

## Примеры кода

- Все примеры оформлять в блоках ` ```scss ` (не `css`).
- Каждый пример подписывать однострочным комментарием `//` внутри блока кода — первой строкой перед самим примером.

```scss
// Staggered-анимация меню
.nav-list li {
  transition-delay: calc(sibling-index() * 250ms);
}
```
