# Claude Code — инструкции для раздела fe/css

## Примеры кода

- Все примеры оформлять в блоках ` ```scss ` (не `css`).
- Каждый пример подписывать однострочным комментарием `//` внутри блока кода — первой строкой перед самим примером.

## Поддержка браузеров

Рядом с каждым добавляемым или исправляемым свойством указывать поддержку, если она неполная. Флаги добавляются в скобках после названия свойства или заголовка, только если в этом браузере нет поддержки:

- `-ff` — нет поддержки в Firefox
- `-sf` — нет поддержки в Safari
- `-ch` — нет поддержки в Chrome
- `-ed` — нет поддержки в Edge

Пример: `# text-box-trim (-ff)` или `grid-template-rows: masonry (-ff -sf -ch -ed)`.

```scss
// Staggered-анимация меню
.nav-list li {
  transition-delay: calc(sibling-index() * 250ms);
}
```
