# CSS Grid

Двумерная система вёрстки — управляет потоком сразу по двум осям (горизонталь + вертикаль). При активации grid на контейнере создаются линии-границы сетки.

```scss
.container {
  display: grid;        // блочный grid-контейнер (занимает всю ширину)
  display: inline-grid; // инлайновый, не занимает всю ширину строки
}
```

## Основные понятия

- **Grid-линия** — горизонтальная или вертикальная граница; нумеруются от 1 (и от -1 с конца для явной сетки)
- **Grid-трек** — пространство между двумя соседними линиями (ряд или колонка)
- **Grid-ячейка** — пересечение одного ряда и одной колонки
- **Grid-область** — прямоугольник из одной или нескольких ячеек
- **Явная сетка** — треки, заданные через `grid-template-*`
- **Неявная сетка** — треки, создаваемые автоматически при переполнении явной сетки

> `writing-mode` влияет на ориентацию осей: при RTL и вертикальном письме block/inline оси меняются. Grid учитывает это автоматически.

При указании `height` на контейнере высота делится между рядами явной сетки.

## subgrid

Вложенный grid, треки которого выравниваются по трекам родителя. Без `subgrid` вложенный элемент создаёт независимую сетку.

- Неявная сетка внутри `subgrid` не создаётся
- `gap` можно переопределить на уровне вложенного элемента
- Именованные линии наследуются или задаются дополнительно: `subgrid [line1] [line2]`
- Можно применять только по одной оси — колонки `subgrid`, ряды фиксированные

```scss
.grid {
  display: grid;
  grid-template-columns: repeat(9, 1fr);
  grid-template-rows: repeat(4, minmax(100px, auto));
}

.item {
  display: grid;
  grid-column: 2 / 7;             // занимает колонки 2–6 родителя
  grid-row: 2 / 4;
  grid-template-columns: subgrid; // дочерние элементы выравниваются по колонкам родителя
  grid-template-rows: subgrid;
}
```

## masonry (-ff -sf -ch -ed)

Алгоритм "кладки" — элементы упаковываются без фиксированных рядов/колонок (Pinterest-стиль). На данный момент только за флагом в Chrome Canary и Safari TP; в Firefox — за `layout.css.grid-template-masonry-value.enabled`.

```scss
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  grid-template-rows: masonry;    // (-ff -sf -ch -ed) высота рядов определяется контентом
  // grid-template-columns: masonry; // то же, но по горизонтальной оси
}
```
