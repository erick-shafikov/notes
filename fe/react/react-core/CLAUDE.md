# Инструкции для раздела react-core

Все примеры компонентов пишутся в **TSX** (TypeScript + JSX).

При добавлении новых файлов или изменении существующих:

- Примеры кода должны учитывать TypeScript: типизировать пропсы, возвращаемые значения, ref-ы и т.п.
- Использовать `tsx` как язык в блоках кода вместо `jsx` или `js`
- Если тип очевиден из контекста, явную аннотацию можно опустить — но интерфейсы/типы для пропсов обязательны
